# PixelPy 1.8.0 — Pixel Studio

Esta release se publicó antes del cambio de nombre a py.Studio; el título se conserva como registro histórico.

- Nueva identidad visual en Proyectos, Editor, Consola, Notebook, Automatizaciones y Resultados.
- Logo Pixel Spark vectorial, con iconos adaptativos y monocromos para Android.
- Navegación inferior clara, acción principal del notebook y estado de ejecución visible.
- Correcciones de navegación Atrás, cancelación de entrada de scripts, selección de recursos por proyecto y deshacer por archivo.
- Estados vacíos de recursos y consola con indicaciones del siguiente paso.
- Gráficos SVG con controles de zoom, arrastre y captura PNG limitada en memoria.
- CSV con detección de coma, punto y coma y tabulación.
- SDK objetivo Android 16 (API 36); mínimo Android 8 (API 26).

Las propuestas visuales son referencias de diseño. Los ejemplos de librerías que aparecen en ellas no implican que esas librerías estén incluidas en la app.
