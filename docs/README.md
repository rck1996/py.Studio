## Estado y evidencia

La última versión publicada se identifica en la portada del repositorio. Una captura de una build de desarrollo no significa que esa build esté publicada ni que todas las funciones hayan sido verificadas en todos los dispositivos. La galería identifica cada captura por pantalla, tema y equipo; [Experiencia de usuario](experiencia-de-usuario.md) separa las pruebas históricas de la validación de la build actual.
