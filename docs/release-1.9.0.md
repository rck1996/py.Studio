# py.Studio 1.9.0

Primera versión publicada con la identidad py.Studio.

## Novedades

- Nuevo nombre visible, isotipo de capas e iconos de Android para py.Studio.
- Paleta compartida de naranja, crema, negro y neutros en los temas claro y oscuro.
- Marca y textos actualizados en Proyectos, Editor, Notebook, resultados, automatizaciones y widget.
- Documentación y capturas reales renovadas para Galaxy S25+ y Samsung Tab S8.
- Notebook adapta sus acciones a un menú desplegable en teléfono; se mantienen la importación de notebooks y la vista previa de datos.

## Compatibilidad y validación

- Android 8.0 o superior (API 26); SDK objetivo Android 16 (API 36).
- Se conserva el identificador `com.pixelpy.editor` para permitir la actualización sobre instalaciones existentes y mantener sus datos.
- Verificación local de pruebas unitarias, lint y build de desarrollo; revisión visual de ambos temas en Galaxy S25+ y Tab S8.
- El flujo de GitHub compila y firma el APK de producción antes de publicarlo como artefacto de esta release.
